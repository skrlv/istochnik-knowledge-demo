# Проверки 16 ноября 2026

Проверяется демонстрационный продукт; реальные документы, контакты и внешние получатели не использовались. Публичный адрес: https://skrlv.github.io/istochnik-knowledge-demo/. Серверные проверки выполнялись отдельно, на loopback. Браузерная проверка — Chromium, а не обещание совместимости со всеми браузерами и вспомогательными технологиями.

## Воспроизводимые автоматические проверки

Базовый набор `npm run check` прошёл до приёмки: 51 тест движка + 21 тест HTTP-сервера = 72 и сборка `dist/`. После исправления R1 добавлена самостоятельная HTTP-регрессия: текущий набор — **51 + 22 = 73**. Серверные 22/22 и целевые браузерные 19/19 прошли локально; полный набор проверяет официальный workflow при публикации. Стандартные тесты не требуют внешних пакетов или платного API. Серверные тесты создают временные каталоги и закрывают свои порты.

Покрыты точные цитаты и номера строк, формы слов, два источника, отсутствие сведений, неизвестные свойства знакомой темы, неоднозначность между документами и разделами одного документа, удаление/замена, инъекции, испорченный текст, блоки Markdown и лимит фрагмента. Серверные проверки включают запись/перезапуск, конкурирующие POST в одном процессе, статусы, права 0700/0600, Host/Origin, обход путей и симлинки, неверный JSON/UTF-8, лимиты и повреждённое хранилище.

## Пользовательский путь в браузере

| Сценарий | Наблюдённый результат |
|---|---|
| «Как получить доступ в срм?» | Дословный ответ; открытая подсветка строк точно совпадает с ответом |
| «Как восстановить пароль и как вернуть ноутбук?» | Два фрагмента и две открываемые ссылки |
| «Какой бюджет на отпуск?» | Нет подтверждения; нет придуманной суммы |
| Добавить конфликтующий отпуск за 7 дней | Уточнение, две цитаты; правило не выбирается автоматически |
| Загрузить файл, заменить отпуск 14 → 21 день, удалить документ | Актуальная база; прежний ответ сброшен; замена не увеличивает количество документов |
| Смешанная загрузка пустого TXT, PDF, плохого UTF-8, бинарного TXT и корректных MD | Ошибки по именам файлов; корректные документы добавлены, база не потеряна |
| Раздел с попыткой сменить правила | Программа не меняет правила; явная инъекция не используется как ответ |
| HTML в ответе и исходнике | Видимый текст; нет созданных `img`/`script`, выполнения кода или запроса вложенной картинки |
| Изменение вопроса при ожидающем ответе сервера | Старый ответ отброшен |
| Очистка при незавершённой загрузке файла/примера | Документы не восстанавливаются завершением старой операции |
| Редактирование обращения и скачивание JSON до сохранения | Экспорт содержит проверенный отредактированный вопрос/контекст; внешней отправки нет |
| Сохранение, просмотр цитат и изменение статуса | В браузере запись видна локально; в серверном режиме запись попадает в файл |
| Перезагрузка без сохранения | Браузерная очередь/загрузки исчезли, учебный пример загрузился заново |
| Явное включение сохранения, затем перезагрузка | Документы, обращение и статус восстановились |
| Удалить сохранённое | Документы и браузерная очередь очищены, переключатель выключен; другой ключ хранилища не затронут |
| Повреждённый JSON в сохранении | Предупреждение; данные не использованы; учебная база загружается, очистка доступна |

Сетевой журнал публичного сценария загрузки и вопросов не содержит POST или тела документов/вопросов и не содержит внешних API: остаются GET файлов с `skrlv.github.io`. Это относится к сетевому поведению приложения в проверенном сценарии, а не к политике журналов GitHub или возможностям расширений браузера.

## Мобильность и доступность

Проверены 1280 px, 375×812 и 320×568: горизонтальная ширина страницы равна ширине окна. Диалоги источника и обращения помещаются по ширине и прокручиваются по высоте. Escape закрывает источник и возвращает фокус на ссылку. Поля подписаны; фокус виден; результат и ошибки используют live/status-области; уменьшение движения отключает анимацию. Сохранены публичные снимки рабочего стола, мобильного вида и исходника в комплекте передачи проекта. Полный аудит со скринридерами и WCAG-сертификация не выполнялись.

## Исправления независимой приёмки R1–R3

- **R1:** сервер проверяет непустоту и объём тела документа, сохраняя исходную строку без `trim()`. Браузер и сервер используют одну нормализацию CRLF/CR → LF в `parseDocument`. Самостоятельный HTTP-тест сравнивает весь ответ ядра и сервера: ведущие пустые строки, строки 5–6, значимые пробелы/табуляции, LF/CRLF/CR. Цитата равна указанному диапазону нормализованного оригинала; снимки источников сохраняются без изменений через POST/GET и после перезапуска очереди.
- **R2:** первоначальная загрузка учебного примера фиксирует текущий токен мутаций. Её устаревший результат и ошибка не меняют уже выполненную загрузку, очистку базы или удаление сохранённого. Браузерная регрессия удерживает только самый первый ответ `demo-documents.json`, выполняет каждое действие и затем отпускает исходный ответ: документ `arrival` остаётся, обе очистки остаются пустыми.
- **R3:** четыре диалога связаны с собственными заголовками через `aria-labelledby`. Проверены фактические имена средствами `getByRole('dialog', {name, exact:true})`: название открытого документа, «Проверьте обращение», «Вопросы для человека», «Сначала факт, потом ответ». Дерево доступности источника теперь начинается с именованного диалога. Тест не подменяет это утверждением о провале или успехе универсального аудита axe/WCAG.

Целевой сценарий находится в `tests/browser-regression.mjs`; запуск с уже установленным Playwright описан в README. Он закрывает свой браузер и временный сервер. Старые успешные проверки выше сохранены как история исходной приёмки; новый прогон ограничен затронутыми сценариями и коротким путём ответа/отказа/обращения.

## Пределы результата

Лексический алгоритм может попросить уточнение или не найти ответ из-за формулировки; например, одно значимое слово не является достаточным основанием. Не выполняются смысловая проверка истинности, выбор действующей редакции и универсальное распознавание инъекций. PDF/DOCX/OCR и импорт очереди отсутствуют. Публичная очередь не общая для устройств; сервер однопользовательский, без входа и внешних уведомлений. Тесты не доказывают пригодность для секретных данных или промышленного развёртывания.
